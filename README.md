# 💼 Sales & Profit Performance Dashboard

This repository showcases an interactive Tableau dashboard analyzing key metrics related to sales, profit, and product category performance.

🔗 [View Live Tableau Dashboard](https://public.tableau.com/app/profile/qing.guo1038/viz/SalesProfitPerformanceDashboard_17441408026490/SalesDashboard)

## 📊 Dashboard Preview

[Sales Dashboard Screenshot](assets/sales-dashboard-preview.png)

## 📈 Key Insights

This dashboard visualizes:
- Total and segmented sales and profit trends
- Top-performing product categories and subcategories
- Regional performance breakdowns
- Year-over-year comparisons

Built with Tableau using simulated or historical sales data for storytelling purposes.
